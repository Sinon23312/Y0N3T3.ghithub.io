Y0N3T3 - instructiuni de pornire
================================

1. Descarca arhiva Yonete.zip si extrage folderul.
2. Deschide folderul Yonete.
3. Intra in folderul images si adauga imaginile campionilor.
   Exemple de nume: Ahri.png, Garen.png, Teemo.png.
   Numele fisierului trebuie sa corespunda cu numele introdus pe site.
   Pentru optiunile "ce vrei tu", "ce vreau eu" sau "secret", foloseste:
   images/secret.png
4. Recomandat: salveaza imaginile in format PNG. Extensia din cod este .png.
   Daca ai JPG sau WEBP, modifica functia imagePath din script.js.
5. Deschide index.html in Chrome, Edge sau Firefox.
6. Autentificare:
   Login: Yonete
   Parola: PicioareleLuiCezar!
7. Adauga campioni in oricare sectiune. Selecteaza AP sau AD si foloseste + / -
   pentru a seta numarul de jocuri. Dupa adaugare poti modifica numarul si din
   lista sau sterge un campion cu butonul x.
8. Butonul "Sterge toate selectiile" curata lista sesiunii curente.

STRUCTURA
Yonete/
  index.html
  style.css
  script.js
  images/
    placeholder.svg
    Ahri.png
    Garen.png
    secret.png

IMPORTANT DESPRE SECURITATE
Acesta este un site static, potrivit pentru folosire locala/personala. Loginul si
parola sunt in script.js, deci o persoana care inspecteaza fisierele le poate afla.
Nu folosi aceeasi parola pentru conturi importante si nu publica site-ul online
cu aceasta metoda de autentificare. Pentru autentificare reala pe internet este
nevoie de un server/backend.
